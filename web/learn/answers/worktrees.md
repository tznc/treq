# Git Worktree Answers

_Fixes and explanations for common git worktree errors and setup questions._

A [git worktree](/learn/concepts/git/git-worktrees) is a second working directory attached to the same repository. Worktrees are how most tools isolate parallel coding agents, so their errors show up often. Each answer below covers one error or question.
