# Sandbox Providers for AI Coding Agents

_A coding agent in the cloud needs a machine it can break. These providers rent you one by the second._

A sandbox is an isolated machine an agent can run commands on without touching your laptop. Coding agents need more than a code interpreter: a Git checkout, package installs, a test run, and often a session that lasts hours. This page compares the providers built for that work. Prices are list prices for compute only, taken from each provider's pricing page in November 2026. Check the provider before you commit, because sandbox pricing changes often.

| Daytona | Containers and VMs | about $0.17 | $200 credit |

| Modal | Sandboxes | about $0.24 | $30 per month on Starter |

Boat, Cloudflare, Vercel and Fly.io price differently, so they are not in the table. Boat bills per second for a persistent VM. Cloudflare needs the $5 per month Workers Paid plan plus Containers usage. Vercel bills active CPU only, so an idle sandbox costs less than a busy one. Fly.io Machines start at about $6.70 per month for 1 shared vCPU and 1 GB.

## What Matters for Coding Agents

- **Session length.** Agents can run for hours. E2B caps a session at 1 hour on its free Hobby plan and 24 hours on Pro.
- **Persistence.** A sandbox that keeps its disk lets the agent resume without cloning and installing again. Boat and Vercel Sandbox keep state by default. Most others offer snapshots.
- **Idle cost.** An agent spends much of its time waiting for the model. Vercel bills only active CPU, and Blaxel bills nothing while a sandbox is suspended.
- **Forking.** Boat can fork a sandbox, which lets several agents start from one prepared environment.
- **Self-hosting.** Beam publishes its engine as open source. Northflank can run in your own AWS, GCP or Azure account.

## The Providers

**E2B** runs each sandbox in a microVM, with SDKs for Python and JavaScript and pause and resume.

**Daytona** creates sandboxes in under 90 milliseconds by its own measure and bills CPU and memory per hour.

**Boat** gives each sandbox a persistent Ubuntu VM with its own kernel, so Docker, systemd and cron work inside it. It supports snapshots and forks.

**Cloudflare** runs each container instance in a microVM with its own kernel, driven by the TypeScript Sandbox SDK.

**Vercel Sandbox** runs Firecracker microVMs that save their state when they stop.

**Modal** bills the larger of requested and used resources, and suits agents that also need GPUs.

**Runloop** isolates at the microVM level and holds SOC 2 Type II.

**Northflank**, **Blaxel**, **Beam** and **Fly.io** round out the list with low list prices, near-instant resume, an open source engine, and plain VMs respectively.
