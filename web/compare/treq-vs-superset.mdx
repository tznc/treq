# Treq vs Paradev (formerly Superset)

_Two local-first ADEs for different workflows: stacked changes or broad agent control._

Superset is now called Paradev. Its old site redirects to paradev.com, and its CLI is still `superset`. Treq and Paradev both run coding agents in isolated workspaces and give you a place to review the result. Facts about Paradev were checked against its site, docs and repository in November 2026.

Treq is built around human review, stacked workspaces, auto-rebase, and sending conflicts back to the agent. Paradev is built around running many CLI agents in parallel. It also sells paid plans for teams.

## At a Glance

| | Treq | Paradev |
| --- | --- | --- |
| Positioning | Stacking ADE, open-source Graphite alternative | Desktop app for running CLI agents in parallel |
| Desktop platforms | macOS, Windows and Linux | macOS, with an experimental Linux AppImage. No Windows build |
| Isolation model | Jujutsu workspaces over a colocated Git repo | Git worktrees per task |
| Review surface | PR-style diffs, line comments sent back to the agent | Changes pane, plus a PR pane for checks, review threads and merge |

| Conflict handling | Send resolution instructions to the agent | Manual, unless you drive it yourself |
| Provider model | Claude, Codex, Cursor, and Copilot | Any CLI agent, with 15 listed as supported |
| Remote or cloud workspaces | [Roadmap](/roadmap): SSH remote development | Remote access on Pro, cloud workspaces on Team and Ultra |
| License | Apache 2.0 | MIT |
| Pricing | Free desktop, [Pro](/pricing) at $15 per user per month | Free, Pro $20, Team $60, Ultra $200 per user per month, Enterprise custom |

## What Each Product Does

**Treq** is a desktop Stacking ADE. Each agent gets an isolated workspace with its own working copy, terminal, and line of history. You arrange dependent workspaces into a stack, review each layer, and send comments back to the agent. When a lower layer moves, Treq rebases the workspaces above it. If a rebase hits a conflict, you send it to the agent instead of resolving it by hand.

**Paradev** is a local-first desktop workspace for many coding agents. It launches CLI agents in isolated Git worktrees and adds chat, browser, review, and automation tools. Its public materials focus on parallel scale, integrations with GitHub, Linear, and Slack, plus paid plans for teams.

Both products solve the same first problem. Several agents should not share one checkout, so each task gets its own directory. See [agent orchestration](/learn/concepts/ai-engineering/agent-orchestration) for why that isolation is required.

## Where They Differ

Both products run parallel agents in isolated workspaces. Git worktrees give Paradev isolation. They do not give it Treq's automatic rebase of a dependent stack. Treq uses colocated [Jujutsu workspaces](/docs/concepts/workspaces) so a target move can rebase every layer above it in the background.

Paradev's PR pane does understand stacks. It reads GitHub's own stack, or infers one from base branches, merges every open layer below a PR, and offers a restack once a lower layer has merged. It does not document rebasing dependent worktrees while the lower layer is still changing, which is the step Treq automates.

Treq organizes agent work as linked, reviewable layers. A large feature should ship as smaller PRs that stay in sync. Diff comments return to the agent. Auto-rebase keeps the stack current. Conflicts stay in the review loop instead of becoming a separate merge chore.

Paradev focuses on breadth. Its public materials feature provider coverage, automations, remote workspaces, and team plans. This model fits teams that want one control plane for many agents, including agents Treq does not list today.

Running many agents is becoming a standard feature. Treq's distinction is the stack that connects their work. That workflow must track each dependency, review layer, and rebase.

## Pricing and Licensing

Treq's desktop app is free and open source under Apache 2.0. [Pricing](/pricing) lists Free for any repository and Pro at $15 per user per month. Local review stays on your machine either way.

Paradev lists Free, Pro at $20, Team at $60, Ultra at $200, and custom Enterprise plans. Its code is open source under the MIT license.

In both cases you still pay the underlying model providers for Claude, Codex, or any other agent usage.

## Who Should Choose Which

Choose **Treq** if you:

- Care more about reviewing and shipping AI-generated code than about launching the largest number of agents.
- Want stacked workspaces, automatic rebasing, and agent-driven conflict resolution as the default workflow.
- Prefer Apache 2.0 and a local-only review loop until you opt into GitHub features.
- Are looking for a Graphite-like stacked workflow built for coding agents.

Choose **Paradev** if you:

- Work on a Mac and need broad CLI agent support and frequent provider switching.
- Want remote workspaces, automations, and team or enterprise packaging today.
- Prefer a product that already has self-serve team plans and compare content.
- Care more about orchestration breadth than stacked PR discipline.
